# 🎭 RigStudio ক্যারেক্টার শিট — সম্পূর্ণ গাইড (V5)

> এই একটা ফাইলে সবকিছু আছে: আপনার ক্যারেক্টারের PNG **কেমন হবে, কোন অঙ্গ কোথায় থাকবে,
> কত সাইজের হবে, হাত-পা আলাদা হবে কি না** — সব বিস্তারিত। শেষে রেফারেন্স ইমেজ ও
> রেডিমেড উদাহরণের লিংক আছে।

## ১. মূল ধারণা — ৩০ সেকেন্ডে

আপনি **একটা PNG ফাইল** বানাবেন → RigStudio সেটাকে **অটোমেটিক** কেটে (extract) →
হাড় বসিয়ে (rig) → ১৮টা অ্যানিমেশন চালিয়ে দেবে। AI নেই, ইন্টারনেট নেই — অ্যাপ
আগে থেকেই জানে কোন বক্সে কী থাকে।

**সবচেয়ে জরুরি কথা:** ক্যারেক্টারটা **কাগজের পুতুল (paper doll)** এর মতো টুকরো টুকরো হতে
হবে — প্রতিটা অঙ্গ **নিজের নির্দিষ্ট বক্সে (স্লটে)** আলাদাভাবে আঁকা থাকবে।
একটা পুরো দেহের ছবি দিলে **হবে না** — অ্যাপ প্রতিটা বক্স আলাদা করে কেটে নেয়।

```
  ┌───────────────────────────────────────────────┐
  │  HEAD    │ TORSO  │arm│arm│hand  │ EYE │ EYE  │
  │  (বড়)   │ (লম্বা) │ L  │ R  │ slots│ EYE │ EYE  │
  │──────────│────────│────│────│──────│ MOUTH ...  │
  │ thigh │thigh│ foot │     (মুখ/চোখ ১৬টা ডান পাশে)
  │ shin  │shin │ slots│
  │ ...লেগ স্লট নিচে...│  সাইড ভিউ একদম নিচে বাম-দানে
  └───────────────────────────────────────────────┘
        2048 × 2048 পিক্সেল, স্বচ্ছ (transparent) PNG
```

## ২. ফাইলের নিয়ম (একদম ঠিক হতে হবে)

| নিয়ম | বিবরণ |
|---|---|
| সাইজ | **ঠিক 2048 × 2048 পিক্সেল** (ইঞ্চি/DPI নয়, পিক্সেল) |
| ফরম্যাট | **PNG** (JPG হলে ভেতরে রূপান্তর হয়, কিন্তু স্বচ্ছতা থাকে না বলে PNG-ই দিন) |
| ব্যাকগ্রাউন্ড | **সম্পূর্ণ স্বচ্ছ (transparent)** — কোনো রঙা ব্যাকগ্রাউন্ড/চেকার নয় |
| কালার | RGBA (রঙ + আলফা চ্যানেল) |
| বক্সের বাইরে | কোনো আঁকিয়া দাগ (ink) থাকবে না — থাকলে "stray ink" ওয়ার্নিং আসবে ও সেটা বাদ যাবে |
| লেবেল/গাইড | টেমপ্লেটের লেখা/কাঠামো ফাইনাল PNG-এ রাখবেন না — শুধু আপনার আর্ট |

ভুল সাইজ দিলে অ্যাপ নির্দিষ্ট বার্তা দেখায়:
*"RigStudio Character Sheet must be 2048×2048 PNG."*

## ৩. অঙ্গগুলো কি আলাদা থাকবে? — হ্যাঁ, এভাবে

মোট **৬০টা স্লট**। প্রতিটা অঙ্গ নিজের স্লটে **স্বাধীনভাবে** থাকবে — কোনো দুটো অঙ্গ
একসাথে জোড়া থাকবে না:

- ✅ মাথা আলাদা (চোখ/মুখ ছাড়া — ওগুলো আরও আলাদা ১৬টা স্লটে)
- ✅ ধড় আলাদা
- ✅ বাহু ৪ টুকরো: উপরের-বাম, নিচের-বাম, উপরের-ডান, নিচের-ডান (কাঁধ-কনুই আলাদা!)
- ✅ হাত ২টা আলাদা
- ✅ রান ২টা, শিন ২টা (হিপ-হাঁটু আলাদা!), পা/জুতা ২টা আলাদা
- ❌ এক স্লটে দুইটা অঙ্গ একসাথে নয় (যেমন পুরো হাত+বাহু একসাথে)
- ❌ দুই স্লটের আর্ট ওভারল্যাপ/লেগে থাকা নয়

**কেন?** অ্যাপ প্রতিটা টুকরো আলাদা করে হাড়ের জয়েন্টে ঝুলিয়ে ঘোরায় — কনুই বাঁকায়,
হাঁটু ভাঁজ করে। জোড়া থাকলে অ্যানিমেশন ভাঙা দেখাবে।

## ৬. সাইড ভিউ — SIDE LEFT + SIDE RIGHT (৮ + ৮টা স্লট)

সাইড ওয়াক/রানের জন্য। **সামনের ক্যারেক্টার ৯০° ঘুরিয়ে দেখানো হয় না** — সত্যিকারের
প্রোফাইল আর্ট লাগে।
- **Side Left** = ক্যারেক্টারের মুখ **বাম দিকে** (নাক বামে)
- **Side Right** = মুখ **ডান দিকে** (নাক ডানে)

  Side Right বানিয়ে নেওয়া যায় (হরিজন্টালি ফ্লিপ)।

## ৮. Pivot (ঘোরার বিন্দু) — কেন জরুরি

প্রতিটা অঙ্গ একটা নির্দিষ্ট বিন্দুতে ঘোরে — ঠিক মানুষের জয়েন্টের মতো:

| অঙ্গ | Pivot কোথায় | মানে |
|---|---|---|
| মাথা | ৫০% / ৯০% (নিচের ধার, ঘাড়) | ঘাড় থেকে নাড়ে — ভুরু নয় |
| ধড় | ৫০% / ৮% (উপরের ধার, কাঁধ-বরাবর) | কোমর নয়, উপরের দিক থেকে ঝোঁকে |
| বাহু/রান/শিন | ৫০% / ৮% (উপরের ধার) | কাঁধ/হিপ/হাঁটু থেকে দোলে |
| পা (জুতা) | ৮৫% / ৫০% (গোড়ালির দিকে) | গোড়ালিতে ঘোরে |

**অ্যাপ স্লটের অনুপাতে pivot বসায়**, তাই আর্টওয়ার্ক যত বড়ই হোক, pivot ঠিক থাকে।
তবে ⚠️ **অঙ্গের আর্ট স্লটের মাঝে ~৯০% জায়গা জুড়ে থাকা ভালো** — খুব ছোট করে আঁকলে
জয়েন্ট আর্টের বাইরে পড়ে যেতে পারে, তখন অ্যানিমেশন অদ্ভুত লাগে।

## ৯. আঁকার গোপন টিপস (প্রফেশনাল রেজাল্টের জন্য)

1. **সব অঙ্গ সোজা/খাড়া ভাবে আঁকুন** — হাত নিচে ঝুলা, পা সোজা নিচে, পা সামনের দিকে
   তাকানো। বাঁকা অঙ্গ দিলে বিশ্রামের ভঙ্গিও বাঁকা দেখাবে।
2. **প্রোপোরশন মিলিয়ে আঁকুন** — স্লটের সাইজ অনুযায়ী; মাথার স্লট ৩৮৪px চওড়া,
   তাই মাথা পুরো জায়গা নেবে, হাত ১৯২px — ছোট হবে।
3. **একই স্টাইল সব ভিউতে** — একই আউটলাইনের মোটা, একই রঙের প্যালেট, একই আলোর দিক।
4. **বোল্ড আউটলাইন** দিলে কার্টুন-অ্যাপ লুক আসে (Tuni উদাহরণ দেখুন)।
5. **স্লটের ভেতরে ৫–১০% মার্জিন** রাখুন — কাটার সময় কিনারা বাদ যাওয়ার ভয় নেই।
6. স্বচ্ছ মার্জিন থাকলে **অ্যাপ অটো-ট্রিম** করে — কিন্তু কখনো স্লটের সীমানা পার হয় না।
7. **চোখ/মুখ স্লটে ব্যাকগ্রাউন্ড নয়** — শুধু চোখ/ঠোঁট আলাদা করে (যেমন সাদা চোখ+কালো মণি)।

## ১০. AI দিয়ে শিট বানাতে চাইলে (বাইরে থেকে)

RigStudio নিজে কখনো AI ডাকে না, কিন্তু আপনি বাইরে যেকোনো ইমেজ-জেনারেটরে
টেমপ্লেট আপলোড করে (image-to-image / inpainting) প্রতিটা বক্স আঁকাতে পারেন।
প্রম্পটে বলুন:

> *"A 2D cartoon character sheet on a transparent background, cut-out puppet style:
> separate head, torso, upper arms, forearms, hands, thighs, shins and feet, each
> part inside its own labelled box, flat colors, bold outlines, front view,
> consistent proportions, no text, no background."*

তারপর বক্সের বাইরের অংশ মুছে (erase) স্লট মেনে নামিয়ে আনুন, 2048×2048 করে এক্সপোর্ট করুন।

---

## ১১. ইম্পোর্ট করে টেস্ট

1. অ্যাপ → **Create Character → Import Character Sheet** → PNG সিলেক্ট
2. ভ্যালিডেশন বার্তা দেখুন (যেমন *"Front Head is missing."* — বলে কোন স্লট ফাঁকা)
3. ইম্পোর্ট শেষে সাথে সাথে **তৈরি ক্যারেক্টার** দেখাবে (কাঁচা শিট নয়)
4. কিছু ভুল মনে হলে Settings → ভার্সনে ৭ বার ট্যাপ → **Developer overlays** চালু
   করুন — স্টেজে পিভট, সীমানা, z-order দেখা যাবে
